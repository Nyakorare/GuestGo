# GuestGo Project Description

The GuestGo web-based system was designed to produce an Automated Visitor Management and Gate Access Control System based on artificial intelligence to streamline and secure visitor registration, tracking, and verification processes within institutional environments. The model takes into account challenges for organizations to manage diversified visitor flows, enforce security protocols, and maintain comprehensive audit trails within time frames that are predetermined. It is built upon three-tier architecture with layers of presentation, logic, and data. 

The presentation layer provides a web application through which users can schedule visits, generate QR codes, track visit progress, and access role-specific dashboards. The logic level governs the system's internal operations, such as the Visitor Scheduling Service with place-specific purpose management and advance notice requirements, QR Code Generation and Scanning Service utilizing Reed-Solomon error correction codes, AI-Powered Face Detection and Verification Service based on YOLOv8 object detection models with MediaPipe and BlazeFace fallback mechanisms, Gate Processing Service for entrance and exit workflows with enforced biometric capture, Visit Status Management Service with automated state transitions, Place and Personnel Management Service with availability tracking, Visit Reschedule Service with request and approval workflows, Feedback Collection Service aligned with ISO 25010 quality characteristics, Email Notification Service via Brevo for transactional communications and EmailJS for contact forms, and Audit Logging Service for comprehensive activity tracking. All visitor data, face images, visit records, and audit logs will be securely stored and processed by the data tier, including encrypted biometric archives, in aid of data consistency, integrity, and privacy compliance.

The system operates by initially receiving visit scheduling requests from visitors or administrative staff. It then processes visit parameters including place selection, purpose identification with required advance notice days (0-6 days), date validation within Philippine timezone, weekly visit limit enforcement (maximum 2 visits per week), and optional face enrollment through AI-powered detection. Based on this processing, the system generates unique QR codes encoded with visit identifiers and produces confirmation emails with embedded QR codes. Users can dictate parameters to include visit date, place selection, visit purpose, personnel assignment, and optional biometric enrollment. Through the integration of Machine Learning (ML) and Artificial Intelligence (AI) technologies, the system can detect and verify visitor faces through multi-tier detection pipelines, compare entrance and exit biometric data for security verification, and adapt scanning cadence based on real-time performance metrics.

During gate operations, guards utilize a dedicated dashboard interface equipped with real-time QR code scanning capabilities, adaptive scan scheduling algorithms that dynamically adjust detection intervals based on scan success rates, and enforced face capture workflows that require biometric verification before processing entrance or exit actions. The system validates visit status, checks for flagged visitors, enforces place completion requirements, and updates visit states through deterministic status transition logic. Face detection employs a primary-fallback architecture where YOLOv8 serves as the primary detection engine with MediaPipe as secondary fallback and TensorFlow.js BlazeFace as client-side fallback, ensuring system resilience even during service outages. Detected faces undergo compression to reduce storage footprint by 80-90%, encryption using XOR-based obfuscation with key rotation, and secure storage in encrypted archives.

Face verification compares entrance and exit biometric captures through feature extraction algorithms that normalize face regions to 100×100 pixel grayscale images, apply histogram equalization for lighting normalization, extract feature vectors through Local Binary Pattern-inspired techniques, and calculate similarity scores using correlation coefficients mapped to a 0-1 scale with configurable thresholds (default 0.75). The verification system achieves approximately 90% true positive rate and 5% false positive rate, providing security assurance while maintaining usability.

Visit tracking enables visitors to monitor their visit progress through dedicated interfaces that display visit information, place completion status, gate scanning history, QR code access, and face data review with verification similarity scores. The system supports visit rescheduling workflows where visitors can request one reschedule per visit with reason explanations, personnel receive notification modals for pending requests, and administrators can accept or decline requests with full validation of weekly visit limits, place constraints, and date availability.

Feedback collection implements ISO 25010 quality assessment surveys covering eight quality characteristics (Functional Suitability, Performance Efficiency, Compatibility, Usability, Reliability, Security, Maintainability, Portability) plus overall satisfaction metrics. The system enforces one feedback submission per visit, stores responses via Supabase RPC procedures, displays analytics in administrative dashboards, and rotates public testimonials daily on contact pages using date-seeded pseudo-random selection algorithms.

The method provides a superior and more consistent alternative to conventional manual visitor registration systems, paper-based logbooks, and disconnected security protocols. By integrating AI-powered biometric verification, real-time QR code processing, automated status management, comprehensive audit logging, and quality feedback mechanisms, GuestGo transforms visitor management from a reactive, error-prone process into a proactive, secure, and data-driven operational workflow that enhances security posture, improves visitor experience, and provides actionable insights for continuous improvement.
